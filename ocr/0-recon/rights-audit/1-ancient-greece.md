# Rights audit — §1 Ancient Greece

Audited all 35 text directories under `texts/1-ancient-greece/`. Opened the
actual source file (PDF or EPUB) for 29 of them — every one that has a source
file in its own directory — plus the sibling source of the six that don't
(the three individual Aeschylus plays share `aeschylus-oresteia`'s PG source;
the three individual Sophocles plays share `sophocles-oedipus-trilogy`'s).
Every text checked is a 19th- or early-20th-century English translation of an
ancient work, so translation date/translator, not antiquity, decides. Two
things stood out: **Aristotle's *De Anima* (J.A. Smith) is a genuine 1931
Clarendon Press boundary case** — its title page reads "1931" outright, one
year past the current pre-1931 clean line, and it's a UK not US publication,
so simple-rule public domain doesn't apply; and **Ptolemy's *Almagest* is
already withheld** (`metadata.withheld.json`, not `metadata.json`) with
Toomer's 1984 translation, the exact case named in this charter's own
examples. Every Project Gutenberg-sourced text (21 of the 35) carries PG's own
"not protected by U.S. copyright law" front-matter language, which I treated
as corroborating, not dispositive, evidence alongside the visible translator/
date.

## undetermined

Aristotle, De Anima, undetermined — title page of 2015.504957.de-anima.pdf opened directly and reads plainly: "DE ANIMA / BY J. A. SMITH... OXFORD / AT THE CLARENDON PRESS / 1931." This is one year past the current pre-1931 clean line, and it is a UK (not US) first publication, so the simple US-publication rule does not resolve it either way. What would settle it: whether this was registered/renewed with the US Copyright Office (Stanford's Copyright Renewal Database covers 1923–1963 US renewals but a search did not turn up a definitive entry either way from here), or simply waiting — it enters the clear pre-1931-equivalent window on 1 January 2027, about five months out. metadata.json already carries a 2026-08-10 owner note treating it as PD; this line records that the file itself shows 1931, not something earlier, so the boundary question is real and worth resolving with an actual renewal-database lookup before the site relies on it.

## copyrighted

Claudius Ptolemy, Almagest, copyrighted — G.J. Toomer's 1984 Princeton translation; this is the exact case named in the audit charter's own examples. Already withheld in this repo (`metadata.withheld.json` rather than `metadata.json`, and no metadata.json present). Toomer died in 2025 so permission is not straightforwardly available, but the work itself (Ptolemy, ~150 CE) is free — translate from Halma's 1813 French edition or an older Greek/Latin edition instead.

## Metadata corrections

- Aeschylus, Prometheus Bound (`aeschylus-prometheus-bound/metadata.json`): `year_translated` reads 1908. Buckley's translation itself dates to circa 1849 (Bohn's Classical Library); 1908 may be a later reprint date carried over from a catalog record. Does not change the publishability verdict either way, both are pre-1931, but the field is likely wrong.
- Ptolemy, Almagest: no `metadata.json` exists in `texts/1-ancient-greece/ptolemy-almagest/`, only `metadata.withheld.json` — flagging in case the merged worklist expects every directory to have one.
