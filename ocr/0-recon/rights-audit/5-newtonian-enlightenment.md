# Rights audit — 5-newtonian-enlightenment

Audited all 26 text directories in this slice; opened the source PDF's title/copyright pages for
every one of them (no directory lacked a source file). The era lived up to the brief: most of it
is English-language originals, clear on date alone. Two texts turned out to be exactly the trap
the brief warned about — a modern academic translation sitting in otherwise-ancient-looking
company: Kant's *Groundwork* is the Allen W. Wood/Yale UP 2002 translation (copyrighted, in
print), and Leibniz's *Explanation of Binary Arithmetic* carries an explicit `© Lloyd Strickland
2007` line on its last page, confirming the concern already on record in project memory. One
minor surprise: `bernoulli-ars-conjectandi-french`'s source file is entirely in Latin (the 1713
*editio princeps*, Basel) — I found no French translation in it despite the directory name; it is
still clearly public domain either way, so this doesn't change the verdict, just the directory's
label.

## translation needed

Kant, Groundwork for the Metaphysics of Morals, translation needed — this file is Allen W. Wood's translation, Yale University Press, copyright 2002, explicit rights-reserved notice, still in print; the 1785 German work itself is long PD — translate fresh from a public-domain German text (e.g. the Reclam/Akademie-adjacent 19th-century editions), or substitute a pre-1931 English translation such as Thomas Kingsmill Abbott's (1873, frequently reprinted)
Leibniz, Explanation of Binary Arithmetic, translation needed — the last page reads "© Lloyd Strickland 2007," so this is a copyrighted modern translation of Leibniz's 1703 French manuscript (Gerhardt VII); translate fresh from Gerhardt's edition of the French original, which is public domain
