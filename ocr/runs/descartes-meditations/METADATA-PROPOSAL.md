# Metadata wording proposal

The current `source/metadata.json` describes a different translation. The
supplied title page identifies William Molyneux as translator and 1680 as the
imprint year. The final scope also includes Hobbes's Third Objections and
Descartes's Answers, not only the six meditations.

Recommended catalog wording, for the adopter to decide:

- **Title:** *Six Metaphysical Meditations, with Hobbes’s Objections and Descartes’s Answers*
- **Description:** *William Molyneux’s 1680 English translation of Descartes’s six Metaphysical Meditations, together with Hobbes’s Third Objections and Descartes’s replies.*

A source-title alternative is *Six Metaphysical Meditations*. It is shorter and
matches the title page exactly, but it does not make the included objections and
answers visible in catalog results.

Other metadata corrections supported directly by the supplied title page:

- `translator`: `William Molyneux`
- `year_translated`: `1680`
- proposed markdown filename: `descartes-meditations.md`
- proposed format on adoption: `markdown`

No change to `ocr_status` is proposed here. Adoption policy may set the work to
`needs-review`; this run does not claim full human proofreading.
