# Proposed transcription

Adopt `spinoza-ethics.md` as the transcription of Baruch Spinoza's *Ethics*,
translated by R. H. M. Elwes.

The complete five-part work was extracted source-natively from the supplied
Project Gutenberg EPUB and rebuilt reproducibly. The supplied PDF's complete
work stream agrees with the EPUB across 108,535 normalized tokens; because both
are renderings of the same Gutenberg transcription, that proves conversion
fidelity rather than correctness against an independent printed witness. The
controlled diagnostic triad passes, but the text contains no mathematical
notation, so that result is only renderer hygiene. The proposal therefore
belongs at `needs-review`, not `complete`.
