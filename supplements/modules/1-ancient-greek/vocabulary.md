# Ancient Greek Module — Master Vocabulary

This is a cumulative vocabulary list for the Ancient Greek module. Words are organized by domain. Use this as a reference alongside your reading — not as a memorization checklist.

The vocabulary in each chapter's text is a curated subset of this list. This master list goes deeper, providing additional words you will encounter as you read more widely.

| Greek | Transliteration | Meaning | Notes |
|-------|----------------|---------|-------|
| καί | kai | and, also, even | Most common connector |
| δέ | de | but, and (mild contrast) | Postpositive (always 2nd+ word) |
| γάρ | gar | for, because | Postpositive |
| οὖν | oun | therefore, then | Postpositive |
| ἄρα | ara | therefore, so | Stronger conclusion |
| ἀλλά | alla | but (strong contrast) | |
| εἰ | ei | if | |
| ἐάν | ean | if (with subjunctive) | |
| ἐπεί | epei | since, when | |
| ὅτι | hoti | that, because | |
| μέν | men | on the one hand... | Always paired with δέ |
| οὐ / οὐκ / οὐχ | ou / ouk / ouch | not | Form varies before vowels |
| μή | mē | not | Used with non-indicative moods |
| ὡς | hōs | as, how, that, in order that | Extremely versatile |
| τε | te | and (enclitic) | Often paired: τε...καί |
| δή | dē | indeed, certainly | Emphatic |
| ἤ | ē | or | |
